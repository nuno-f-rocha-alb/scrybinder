# Contributing to Scrybinder

Thanks for your interest! Bug reports, misidentified-card reports, documentation fixes and code are all welcome.

## Reporting a problem

* **A card was identified wrongly** — open an issue with the template. Attach the photo if you can (crop it to the card), say what the card really is (name, set, collector number, finish) and what Scrybinder returned. Mention whether the visual index was built (*Settings → Visual index*) and the camera or phone you used. Misread cards are the most valuable bug reports.
* **Anything else** — include your OS, how you installed (installer, portable zip, source), the Scrybinder version (*Settings*) and, for packaged builds, the end of `scrybinder.log` in your data folder.

## Development setup

```bash
uv sync --extra vision                 # CPU PyTorch; use --extra vision-cuda for an NVIDIA GPU, no extra for OCR only
cd ui && npm ci && npm run build && cd ..
uv run pytest                          # ~70 tests, ~40 s; tests that need Tesseract are skipped without it
uv run scrybinder --browser            # run in a browser tab; add --serve to just print the URL
cd ui && npm run dev                   # optional: Vite dev server for UI work (proxy the API with --serve)
```

You need Python 3.12, [uv](https://docs.astral.sh/uv/), Node.js 20+ and [Tesseract](https://github.com/tesseract-ocr/tesseract). See [docs/BUILDING.md](docs/BUILDING.md) for packaging.

## Making a change

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Keep pull requests focused. Add or update tests (`tests/`); the UI is type-checked by `npm run build`.
3. Match the surrounding style: short comments that explain *why*, no speculative abstractions, English throughout (UI text, messages, comments).
4. Do not commit personal data: `data/`, photos of your collection, CSV exports. Test fixtures are generated by `tests/make_fixtures.py` from public data.
5. By contributing you agree that your contribution is licensed under the [MIT License](LICENSE).

## Ideas that would help

* Test photos for hard cases (old frames, foils, other languages) — as issues, not in the repository.
* A UI translation layer; the UI is currently English only.
* Linux and macOS testing of the experimental builds, and camera backends.
* Better handling of Room / split cards and strong foil glare (see *Accuracy and limitations* in the README).

## Conduct

Be kind and constructive. Harassment or personal attacks are not tolerated; maintainers may remove comments or contributors that break this rule.
